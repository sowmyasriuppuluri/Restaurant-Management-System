# Restaurant Management System

## About the Project
A web-based Restaurant Management System developed during my Full Stack Java internship at Infoz IT Solutions. It allows users to browse menu items, view prices, manage cart quantities, calculate the total bill, and place orders.

## Features
- Browse menu items with prices
- Filter food items by category
- Add items to the cart
- Increase or decrease item quantities
- Calculate the total bill
- Place orders and view order records

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Java, Spring Boot
- **Database:** MySQL

## How to Run
1. Clone or download the repository.
2. Open `index.html` in a browser to access the frontend.
3. Run the Spring Boot application using your Java IDE.
4. Configure the database connection if required.
